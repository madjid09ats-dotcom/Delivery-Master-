# Delivery Master

Jeu HTML5 de livraison en format paysage. Ramasse 3 colis, évite les obstacles et atteins le dépôt. Les pièces permettent de débloquer des véhicules.

## Mise en ligne avec GitHub Pages
1. Décompressez cette archive.
2. Dans votre dépôt GitHub, choisissez **Add file > Upload files**.
3. Téléversez tous les fichiers contenus dans ce dossier (pas le dossier ZIP).
4. Validez avec **Commit changes**.
5. Ouvrez **Settings > Pages**.
6. Dans **Build and deployment**, choisissez **Deploy from a branch**, branche **main**, dossier **/(root)**, puis **Save**.

Le jeu est un prototype. Les publicités, les comptes joueurs, le classement mondial et les paiements ne sont pas intégrés.
